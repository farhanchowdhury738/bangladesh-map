# Bangladesh Interactive Administrative Hierarchy

An interactive and responsive web project that shows the administrative structure of Bangladesh.

## Features
* Bangladesh → Division → District → Upazila navigation
* 8 Divisions
* Interactive search bar
* JSON-based data
* Responsive design for mobile, tablet and desktop
* Smooth animations

## Technologies
* HTML
* CSS
* JavaScript
